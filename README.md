# WeTi
Professional keybind designer for game development

## Development

Install dependencies:

  npm install

Run dev server:

  npm run dev

This scaffold contains a minimal React + TypeScript web app with:
- Key capture component
- Bind list and JSON export
- Profile schema and export utility

Next steps:

- Add profiles & presets management
- Add gamepad support and UI polish
